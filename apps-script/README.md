# Google Apps Script 後端安裝

這個後端會在一份**未公開的私密借用資料庫**中建立兩張工作表：`借用申請`、`借用項目`；照片會依申請編號分別存到 Google Drive 的 `領用照片` 與 `歸還照片` 子資料夾。公開器材清單只能用來顯示目錄，不應儲存姓名、學號或電話。

1. 建立一份新的 Google 試算表，名稱可為「北醫影創借用資料庫」，並維持「受限制」分享設定。從網址複製試算表 ID。
2. 建立一個專門存放借還照片的 Google Drive 資料夾，分享設定必須是「受限制」或只限校內網域；**不可**設為「知道連結的任何人」。複製資料夾 ID。
3. 以器材試算表擁有者帳號開啟 [Apps Script](https://script.new)，貼上完整 `Code.gs` 後，從左側 **專案設定 → 指令碼屬性** 新增：
   - `REQUEST_SPREADSHEET_ID`：私密借用資料庫試算表 ID
   - `PHOTO_ROOT_FOLDER_ID`：受限制的照片資料夾 ID
   - `ADMIN_KEY`：長且不易猜測的管理密碼
4. 儲存後執行 `setupDatabase` 一次，並同意 Google Drive、Google Sheets 與 Gmail 寄信的授權。這會建立借用日期、預計歸還日期、電子信箱與歸還驗證碼雜湊欄位。
5. 點選 **部署 → 管理部署作業 → 編輯 → 新版本 → 部署**。
6. 「執行身分」選擇 **我**；「誰可以存取」選擇 **所有人**。這樣訪客可提交申請，但只有你的帳號有權寫入私密資料庫與 Drive。
7. 複製部署的 `/exec` 網址，貼到網站根目錄的 `app.js` 中 `API_URL` 常數。

每次調整 `Code.gs`，請在 Apps Script 的部署管理中建立新版本，然後重新部署。請勿把 Google Apps Script 的專案 ID、OAuth token 或任何管理員帳密放進網站。

每筆申請會產生純數字編號，例如 `20260902001`（日期 `yyyymmdd` 加上當日三位流水號），並寄送申請確認、借用日期、器材清單與一組 12 碼的**歸還驗證碼**到借用人填寫的電子信箱。歸還時必須同時輸入兩者；驗證碼只會以雜湊形式存在私密資料庫。

## 啟用「依姓名管理借用」

這個功能可顯示尚未歸還的借用人資料，因此必須設定只有管理者知道的密碼：

1. Apps Script 左側點選 **專案設定** → **指令碼屬性**。
2. 新增屬性：名稱填 `ADMIN_KEY`，值填一組長且不易猜測的管理密碼。
3. 儲存後建立新的部署版本。管理者從管理頁面辦理歸還時不需借用人的驗證碼。

密碼只會在管理者開啟「管理借用紀錄」並搜尋姓名時送到後端，不會寫入網站原始碼或公開試算表。

## 對外開放前請注意

「所有人」表示任何知道網址的人都可送出包含姓名、學號、電話與照片的申請，後端也會替你把檔案寫入 Drive。此版本已限制單次照片數量、驗證歸還碼與嘗試頻率，但公開申請仍可能被濫用；若流量變大，應再加上校內登入或 CAPTCHA。包含借用照片與私密借用資料庫都不應設為公開瀏覽。

## Cloudflare 零預算版：把 GAS 改為私有照片／寄信橋接

只有完成 `cloudflare-worker/README.md` 的 Worker 測試後才做本節。新版網站會將借用資料放在 Cloudflare D1；Apps Script 只負責把照片放到**受限制的** Google Drive，並從你的 Gmail 寄確認信。

1. 把本資料夾最新的 `Code.gs` 完整貼到既有 Apps Script 專案並儲存。
2. 在 **專案設定 → 指令碼屬性** 新增 `CLOUDFLARE_INTERNAL_TOKEN`。它必須和 Worker 的 `GAS_INTERNAL_TOKEN` 一字不差；這是一組只給兩台伺服器使用的長隨機密鑰，不能貼進網站、GitHub 或聊天室。
3. 重新部署 Web App，維持「執行身分：我」與「誰可以存取：所有人」。這是讓 Worker 能呼叫 Apps Script 的必要設定；但沒有內部密鑰的請求會被拒絕。
4. 先不要設 `CLOUDFLARE_ONLY`。等 Worker 的借用、寄信、照片上傳與歸還都測試成功後，才新增 `CLOUDFLARE_ONLY`，值填 `true`，重新部署一次。此時舊版網站直接呼叫 GAS 的 action 會被關閉。

不要刪除原本的 `REQUEST_SPREADSHEET_ID`、`PHOTO_ROOT_FOLDER_ID` 與 `ADMIN_KEY` 屬性；私有 Drive 寫入與管理流程仍會用到它們。
