# Google Apps Script 後端安裝

這個後端會在一份**未公開的私密借用資料庫**中建立兩張工作表：`借用申請`、`借用項目`；照片會依申請編號分別存到 Google Drive 的 `領用照片` 與 `歸還照片` 子資料夾。公開器材清單只能用來顯示目錄，不應儲存姓名、學號或電話。

1. 建立一份新的 Google 試算表，名稱可為「北醫影創借用資料庫」，並維持「受限制」分享設定。從網址複製試算表 ID。
2. 以器材試算表擁有者帳號開啟 [Apps Script](https://script.new)，將私密試算表 ID 填入 `CONFIG.requestSpreadsheetId`。
3. 將 `Code.gs` 的完整內容貼到專案，儲存後執行 `setupDatabase` 一次，並同意 Google Drive、Google Sheets 與 Gmail 寄信的授權。這會建立借用日期、預計歸還日期與電子信箱欄位。
4. 點選 **部署 → 新增部署作業 → 網頁應用程式**。
5. 「執行身分」選擇 **我**；「誰可以存取」選擇 **所有人**。這樣訪客可提交申請，但只有你的帳號有權寫入私密資料庫與 Drive。
6. 複製部署的 `/exec` 網址，貼到網站根目錄的 `app.js` 中 `API_URL` 常數。

每次調整 `Code.gs`，請在 Apps Script 的部署管理中建立新版本，然後重新部署。請勿把 Google Apps Script 的專案 ID、OAuth token 或任何管理員帳密放進網站。

每筆申請會產生純數字編號，例如 `20260902001`（日期 `yyyymmdd` 加上當日三位流水號），並寄送申請確認、借用日期與器材清單到借用人填寫的電子信箱。

## 啟用「依姓名管理借用」

這個功能可顯示尚未歸還的借用人資料，因此必須設定只有管理者知道的密碼：

1. Apps Script 左側點選 **專案設定** → **指令碼屬性**。
2. 新增屬性：名稱填 `ADMIN_KEY`，值填一組長且不易猜測的管理密碼。
3. 儲存後建立新的部署版本。

密碼只會在管理者開啟「管理借用紀錄」並搜尋姓名時送到後端，不會寫入網站原始碼或公開試算表。

## 對外開放前請注意

「所有人」表示任何知道網址的人都可送出包含姓名、學號、電話與照片的申請，後端也會替你把檔案寫入 Drive。第一次建議先只提供給小範圍測試；若要公開在網際網路，請至少加上校內登入、驗證碼或 CAPTCHA 與流量限制，避免遭到惡意大量上傳。包含借用照片的 Drive 資料夾也不應設為公開瀏覽。
