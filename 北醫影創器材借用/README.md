# 北醫影創器材借用

## 目前功能

- 讀取公開 Google 試算表的器材資料，提供搜尋、品類與借用單位篩選。
- 所有列於器材目錄的品項都可選擇借用數量；網站不再使用舊試算表的「可借／借出」欄位做限制。
- 借用人必填姓名、學號、電話、電子信箱、借用日期與預計歸還日期；選幾件器材，就必須各上傳幾張領用照片，歸還時也相同。
- 每筆申請會以純數字日期流水號（例如 `20260902001`）寄到借用人的電子信箱。
- 以 email 中的申請編號查詢待歸還器材，逐件上傳歸還照片。
- 借用紀錄與照片由 Google Apps Script 寫入試算表及指定的 Google Drive 資料夾。

## 讓所有人開啟

1. 先依 [`apps-script/README.md`](apps-script/README.md) 部署後端，將取得的 `/exec` 網址填到 `app.js` 最上方的 `API_URL`。
2. 前往 [Netlify Drop](https://app.netlify.com/drop)，登入後把這個資料夾拖進網頁。
3. Netlify 會產生一個公開網址；把網址分享給借用人即可。

不要把 `apps-script/Code.gs`、Google Drive 資料夾或試算表的編輯連結放到公開網站。公開網站只需要 `index.html` 與 `app.js`。

## 管理者查看庫存與借用紀錄

請以試算表擁有者或編輯者帳號開啟原本的 Google 試算表：

- 原有器材工作表是目前的庫存清單；網站將所有列出的器材視為在庫。
- 私密「借用資料庫」試算表中的 `借用申請` 工作表記錄借用人、借用／預計歸還時間、申請編號與狀態。以「待確認」或「部分歸還」篩選，即可看到尚未結案的申請。
- 私密「借用資料庫」試算表中的 `借用項目` 工作表記錄每筆申請的器材、數量、領用照片與歸還照片連結。
- 網站右上方的「管理借用紀錄」可用姓名搜尋尚未歸還的紀錄，並直接帶入歸還流程；首次使用前需依後端說明設定管理密碼。

目前借用申請會保存為紀錄，但不會自動扣除原器材清單的數量；目錄上的器材一律視為可申請借用。
